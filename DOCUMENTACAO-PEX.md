# Documentação de apoio — PEX V

## Problema
A empresa parceira utiliza controles manuais para organizar informações de estoque, o que pode gerar retrabalho, divergências e dificuldade de consulta.

## Solução
O StockFlow é um MVP web para cadastro de produtos, consulta de saldos, registro de entradas e saídas e histórico de movimentações.

## Objetivo geral
Desenvolver uma solução digital simples para apoiar a organização e o controle de estoque de pequenos comércios.

## Objetivos específicos
- Modelar os dados de produtos e movimentações;
- Implementar API REST;
- Criar interface web responsiva;
- Validar regras de entrada e saída;
- Executar testes manuais com dados simulados;
- Documentar o código e a execução preliminar.

## Piloto sugerido
Cadastrar produtos fictícios, registrar uma entrada, registrar uma saída válida e tentar uma saída superior ao saldo. Registrar prints das telas e resultados observados.

## Indicadores
- Funcionalidades disponíveis;
- Quantidade de cenários executados;
- Bloqueio de saídas inválidas;
- Facilidade percebida pelos usuários;
- Consistência do saldo após movimentações.

## Limitações
O MVP não possui autenticação, hospedagem pública, relatórios avançados ou integração com sistemas externos.
